# AI Image Understanding and Caption Generator

A Streamlit app that lets users upload images, generate captions, and ask natural-language questions about the content.

## Tech Stack
- Python
- Streamlit
- PIL / OpenCV
- vision-language model API
- optional OCR

## Features
- Image upload
- Caption generation
- Scene explanation
- Visual Q&A
- OCR text extraction

## Setup
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Example questions
- What is in the image?
- Describe the scene.
- What objects are visible?
- Is there any text in the image?
